| Page | File | Built by |
|------|------|----------|
| Home (landing page) | index.html | Michael |
| Menu & Orders (table + form) | order.html | Michael |
| Gallery | gallery.html | Collaborator (to do) |

## Design rules

- Colours: dark green #1f4d3a, orange #f6a623, cream background #fff8ef
- Font: Arial
- Every page uses the same navbar and footer (copy them from index.html)
- Every page uses the shared stylesheet style.css
- Reuse the classes .page, .card and .button
